Install → Describe → Play

From idea to a playable game in three steps

1

Add the plugin

Get the desktop app or drop the plugin into your project. Connect a free AI provider (Gemini, Groq, or local Ollama) — no paid key.

2

Describe your game

Type it in plain English — “a 2D endless runner where a cube jumps over obstacles, space to jump.” Pick a model and hit Generate.

3

Press Play

The AI writes ready-to-run C# into your project. Open an empty scene, press Play, and the game bootstraps itself. Edit the code freely.

Built for Unity, not against it

Real games, right in the Editor

In-Editor plugin

Generate without leaving Unity

A tidy Editor window (Window ▸ UnityGUI) takes your prompt and drops complete C# scripts into your project. No web dashboard, no copy-paste, no exporting.

  • ✔ One-window prompt → generate → play
  • ✔ Editor-only code — never ships in your build
  • ✔ Pick your model per generation
Real assets, not just code

Scenes, prefabs & generated art

Pro mode writes a real .unity scene, prefabs, and procedurally-generated art (sprites, materials, meshes) wired into a playable scene — open it and press Play. Prefer one self-contained script set? Lite mode does that too.

  • ✔ Saved .unity scene + prefabs in your project
  • ✔ Procedural art assets — no downloads
  • ✔ Everything editable in the Inspector
Free AI providers

Free to run — no paid Claude key

Generation runs on a free provider: Google Gemini (free tier, no credit card), Groq (free & fast), or Ollama (100% local and offline, no key). Pick a provider, paste its free key, and go. Your key stays on your machine.

  • ✔ Gemini / Groq free keys · Ollama needs none
  • ✔ JSON-mode output for reliable code
  • ✔ Open source & MIT-licensed
